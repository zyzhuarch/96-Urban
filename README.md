# 用九六都市更新｜Concept Prototype

## 檔案

- `index.html`：單頁結構
- `styles.css`：品牌視覺、四段建物狀態、RWD 與 reduced-motion fallback
- `data.js`：可替換的虛構專案資料
- `app.js`：捲動狀態、MapLibre 基地地圖、專案篩選／選取與表單流程示範
- `assets/96.svg`：由使用者提供的 Logo 副本

## 預覽

直接以瀏覽器開啟 `index.html` 即可預覽。此版本沒有編譯步驟、追蹤或表單資料外傳；基地地圖會透過 MapLibre GL JS 載入公開向量圖磚，因此需有網路連線。

## Prototype 限制

- 專案名稱、位置與文案均為 placeholder，不代表真實案件。
- 地圖以 MapLibre GL JS 與 OpenFreeMap 公開向量圖磚呈現；只繪出行政區邊界、主要道路、水系與概念基地點，沒有地址、建築細節或精準定位。
- 聯絡表單只示範驗證與完成狀態；不會傳送或儲存個資。
- LINE 顯示為預留位置，正式網址填入資料設定後才應啟用。

## 字體使用方式

- h1、h2 使用 cwTeXMing 標題字體。
- h3 到 h6 與一般內文使用 GenJyuu Gothic Light。
- 中文字體已依目前頁面內容製作精簡字集；若增加新文案且出現字型 fallback，需重新產生字集。
- 英文字體使用完整 enfont WOFF，不做子集化；英文文字可加 `class="h7"` 獨立套用。請勿使用無效的 `<h7>` 標籤。

## 接正式資料時

只需修改 `data.js` 中每個專案的 `name`、`location`、`status`、`summary`、`coordinates`。正式版接後台時，表單應送往只有管理者可登入的私有資料服務，且預設關閉 email 通知。

## Loading 入場動畫

- 9 與 6 從隨機方向飛入，載入期間保持微幅錯位。
- 以 0–100% 數字呈現載入進度，不使用進度條；數字代表頁面、字型與圖片就緒狀態，不是精確下載位元組比例。
- 載入完成後，兩個數字合成完整 Logo，並顯示中英文公司名稱；英文名稱會依中文名稱寬度自動調整。
- 載入背景由 `#E2EAD3` 轉為 `#D8901D`。向下捲動會先淡出 loading 畫面，完全淡出後才解鎖頁面捲動；回到頁首會再次顯示完成畫面。
